# Portofoliu Eduard Urzică

Site static, un singur fișier `index.html` + imaginile din `img/`. Nu are build, nu are dependențe.

## Publicare pe Vercel prin GitHub
1. Creezi un repo nou pe GitHub (public sau privat) și urci tot folderul ăsta.
2. Pe vercel.com → Add New Project → alegi repo-ul → Framework preset: **Other** → Deploy.
3. Vercel servește `index.html` din rădăcină. Fiecare push pe `main` republică automat.
